🔑 GitHub Access Token Setup

Configure your GitHub Personal Access Token (PAT) so this admin dashboard can commit files and photos directly to your repository.

  1. Go to GitHub.com > Settings > Developer settings > Personal access tokens.
  2. Generate a token with repo (or Fine-grained token with Contents: Read and write).
  3. Paste the token below. It will be stored safely in your device's browser only.
